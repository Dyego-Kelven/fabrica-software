# Projeto FABRICA

Projeto simples feito com React Native e Expo para a disciplina.

O aplicativo representa uma fabrica de software e permite cadastrar:

- setores;
- cargos;
- funcionarios;
- projetos;
- participacoes dos funcionarios nos projetos;
- tipos de falhas;
- testes;
- dependentes;
- cartoes de progressao.

Os dados cadastrados ficam salvos no aparelho ou navegador.

## Como executar

```bash
cd fabrica-software
npm install
npm start
```

Depois, use o Expo Go para ler o QR Code ou pressione `w` para abrir no navegador.

## Como apresentar no video

1. Mostre o painel inicial.
2. Abra a aba Cadastros e mostre os funcionarios.
3. Cadastre ou edite um funcionario.
4. Mostre os projetos financeiros e administrativos.
5. Mostre a equipe de um projeto.
6. Mostre um teste e as falhas encontradas.
7. Abra a aba Modelo e explique os relacionamentos.
